# Contributing to PawIDE

First off, thank you for considering contributing to PawIDE! It's people like you that make the open-source community such an amazing place to learn, inspire, and create.

## How Can I Contribute?

### Reporting Bugs
This section guides you through submitting a bug report for PawIDE. 
* Make sure you are on the latest version.
* Use the **Bug Report** issue template provided in the repository.
* Include detailed steps to reproduce the bug.

### Suggesting Enhancements
This section guides you through submitting an enhancement suggestion, including completely new features and minor improvements to existing functionality.
* Use the **Feature Request** issue template.
* Provide a compelling reason why this feature should be included.

### Pull Requests
* **Fork** the repo on GitHub.
* **Clone** the project to your own machine.
* **Commit** changes to your own branch.
* **Push** your work back up to your fork.
* Submit a **Pull Request** so that we can review your changes.

NOTE: Be sure to merge the latest from "upstream" before making a pull request!

Welcome to the PawDevs community! Let's build something awesome together.
