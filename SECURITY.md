# Security Policy

## Supported Versions
Currently, only the latest `main` branch of PawIDE receives security updates.

| Version | Supported          |
| ------- | ------------------ |
| v3.0.x  | :white_check_mark: |
| < v3.0  | :x:                |

## Reporting a Vulnerability
If you discover a security vulnerability within PawIDE, please DO NOT open a public issue. 

Instead, please send a direct message or email to the repository maintainer. All security vulnerabilities will be promptly addressed.
